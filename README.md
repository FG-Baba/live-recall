# live-recall

Learning notes on retrieving a short Markdown note from a typed phrase or audio input. The focus is matching short queries and displaying results clearly.

## Areas of Study

- Matching short phrases against a small set of local Markdown notes with low latency.
- Abstaining cleanly when a query is too weak or ambiguous rather than showing a poor match.
- Preventing stale async updates from overwriting a newer query or manual selection.
- Keeping the reading surface minimal, centered, and free of scroll or clutter.
